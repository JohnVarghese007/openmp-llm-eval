#include <stdio.h>

            shared_var = 99;

    }

}

2. **Single Construct**: Within the parallel region, the `#pragma omp single nowait` construct ensures that only one thread (whichever gets there first) executes the block of code that follows. This block assigns the value 99 to `shared_var`. The `nowait` clause indicates that the other threads do not have to wait at the end of this block.

3. **Conditional Print**: The `if (omp_get_thread_num() == 1)` condition ensures that only the thread with ID 1 attempts to print the value of `shared_var`.
